How to fix ModuleNotFoundError: No module named 'pandas'

Python cannot find pandas in the environment running your code. Install pandas through that same Python interpreter, then verify the import.

A practical beginner guide · Reviewed October 13, 2026

THE QUICK FIX

Install into the Python you use

python -m pip install pandas

Then run your script with that same python. On Windows, try py -m pip install pandas if you use the Python launcher.

START HERE

Why does Python say “No module named pandas”?

ModuleNotFoundError means the Python interpreter running your program could not find an importable module named pandas. Most often, pandas is not installed in that interpreter's environment. It may be installed for another Python version, virtual environment, IDE interpreter, or Jupyter kernel.

The installable package is named pandas, and its Python import is also pandas (commonly imported as pd). Installing it once on your computer does not automatically make it available to every Python environment.

STEP BY STEP

How do I install pandas and check that it works?

  1. Open the terminal for the environment that runs your code

    If you work in an editor or notebook, first identify its selected Python interpreter or kernel. Installing in a separate system terminal may target a different environment.

  2. Install pandas with that interpreter

    Use python -m pip so pip is run by the selected Python, rather than an unqualified pip command.

    Windows (Python launcher) 
    py -m pip install pandas
    macOS or Linux 
    python3 -m pip install pandas

    If your project already uses a virtual environment, activate it first and use python -m pip install pandas inside it. See the environment instructions below.

  3. Verify the installation and interpreter

    Run these commands in the same terminal where you launch your program:

    python -c "import pandas as pd; print(pd.__version__)"
python -c "import sys; print(sys.executable)"

    The first command prints the installed pandas version if the import succeeds. The second prints the exact Python executable. If you installed with py -m pip on Windows, use py -c for both checks; otherwise use the same python command you used to install.

  4. Run your program again

    python your_script.py

    Replace your_script.py with your file's name. If you installed with the Windows launcher, run py your_script.py instead. In an IDE, select the same interpreter shown by sys.executable, then run the program again.

Still unsure which environment is active?

Check where pandas is installed with python -m pip show pandas, or py -m pip show pandas if you installed with the Windows launcher. If no package details appear, install it using the same interpreter command.

ENVIRONMENT-SPECIFIC HELP

What if I use a virtual environment, IDE, or Jupyter?

Using a project virtual environment

A virtual environment keeps a project's packages separate. Create one from your project folder, activate it, then install pandas there:

Windows PowerShell 
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install pandas
macOS or Linux 
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pandas

After activation, python should point to the environment. If PowerShell blocks activation, use the Python executable inside .venv directly or follow the official Python Packaging User Guide; avoid changing machine-wide execution policy just to work around this import error.

Using VS Code or another IDE

Editors can run code with an interpreter different from your system terminal. Print sys.executable from the editor's run action, select that interpreter in the editor, and install pandas into it. The VS Code Python environments guide explains interpreter selection.

Using Jupyter Notebook

In a notebook cell, use IPython's %pip command so installation targets the active kernel, then restart the kernel and retry the import:

%pip install pandas
import pandas as pd
print(pd.__version__)

Using Conda

If your project is managed with Conda, activate its environment and install with Conda rather than mixing package managers without a reason:

conda activate my-environment
conda install pandas

Replace my-environment with your environment name. Select that same environment in your editor or notebook.

FIND THE CAUSE

What if installing pandas did not fix the error?

Common pandas import symptoms, likely causes, and next steps
SymptomLikely causeWhat to try
Install says successful, import still fails pip and the script use different Python environments. Run python -m pip show pandas and python -c "import sys; print(sys.executable)" using the interpreter that runs the script.
Works in terminal, fails in editor The editor selected a different interpreter. Print sys.executable from the editor and select or install pandas in that interpreter.
Fails in a notebook only The notebook kernel is different from the terminal environment. Run %pip install pandas in a cell, restart the kernel, and check the selected kernel.
Error mentions another module after pandas imports A separate optional dependency or another package is missing. Read the exact module name in the new error. Install the dependency required for that feature, not pandas again.
Import behaves strangely or resolves to a local file A project file or folder named pandas.py or pandas may shadow the real package. Rename the conflicting local file or folder and its related __pycache__ entry, then restart Python.
python or pip command is not found Python may not be installed or available on PATH. On Windows, try the Python launcher command py. Otherwise install Python from its official source and reopen the terminal.

QUICK ANSWERS

Frequently asked questions

Is pandas the same thing as Python's built-in module?

No. pandas is a third-party Python library. Install it into the environment you use; it is not included with Python itself.

Should I run pip install pandas or python -m pip install pandas?

python -m pip install pandas is usually clearer because it invokes pip through that Python interpreter. On Windows, py -m pip install pandas uses the Python launcher.

Why does import pandas as pd use “pd”?

pd is a widely used short alias for the pandas module. Install the package named pandas, then import it as import pandas as pd.

Do I need to install pandas again for every project?

Only when the project uses an environment where pandas is not installed. Separate virtual environments have separate packages; a shared environment can serve more than one project.

What should I do if the install command reports an error?

Read the full pip error before retrying. It may indicate a network issue, unsupported Python version, permissions issue, or environment problem. Consult the official pandas installation guide and use a supported installation method for your setup.

IN SHORT

The key fix

Install pandas with the same Python interpreter that runs your code: python -m pip install pandas. If the error remains, compare the interpreter path, virtual environment, IDE selection, or notebook kernel before reinstalling.
